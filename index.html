내 PC의 C:\Users\USER\Documents\oCam 폴더를 선택하세요. 영상은 Google Gemini로 보내 분석하고, 분석 결과만 이 브라우저에 저장됩니다. 20MB가 넘는 영상은 화면 캡처(최대 150장)와 음성으로 줄여서 보냅니다.

✍️ 대본 만들기

🔊 TTS 음성 장면별 내레이션을 Gemini 음성으로 만듭니다

🎬 영상 만들기 장면 순서대로 소스 + 음성 + 자막을 합쳐 세로 영상(1080×1920)으로 저장

장면 순서 · 소스 배치

장면마다 보여줄 사진이나 영상을 넣고 ↑↓로 순서를 바꾸세요. 소스가 없는 장면은 상품명 화면으로 나옵니다. 직접 찍었거나 사용 권한이 있는 소스만 쓰세요.

영상 길이만큼 시간이 걸립니다. 만드는 동안 이 탭을 계속 띄워두세요 (다른 탭으로 가면 끊길 수 있음).

⚙️ API 키 설정

키는 이 브라우저에만 저장됩니다.

고급: Gemini 모델 이름 (보통은 비워두세요)
고급: 사용할 Apify 도구 바꾸기

Apify 스토어의 도구 이름(예: username/actor-name)을 넣으면 됩니다. 비워두면 기본값을 씁니다. 입력 이름은 도구의 입력 형식을 읽어서 자동으로 맞춥니다. 필요하면 추가 입력(JSON)을 넣을 수 있습니다.
